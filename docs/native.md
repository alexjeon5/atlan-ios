# 게스트 함수의 네이티브 대체

게스트 이미지 안에 정적으로 링크된 런타임 라이브러리 코드(컴파일러 보조 함수, zlib 등)를 인터프리터로 돌리지 않고 호스트 구현으로 바꿔 실행한다. import를 호스트 서비스로 처리하는 것과 같은 방식을 이미지 내부 함수로 넓힌 것이다. 실행 메모리를 만들지 않으므로 JIT 권한이 필요 없다.

## 원칙

- 특정 빌드의 주소를 전제하지 않는다. 함수는 **export 심볼 이름**으로 찾고, 없으면 임베더가 준 **바이트 시그니처**로 찾는다.
- 찾은 함수는 바꾸기 전에 **자가 검증**한다. 게스트의 원래 코드(인터프리터)와 호스트 구현에 같은 입력을 주고 결과가 같을 때만 바꾼다.
- 못 찾았거나 결과가 다르면 그 함수는 그대로 인터프리터로 실행한다. 원본 `.so`가 바뀌어 함수가 없어지거나 동작이 달라져도 느려질 뿐 깨지지 않는다.
- 호스트 구현은 공개된 인터페이스와 규격(ARM RTABI, zlib.h, RFC 1950/1951)에서 새로 작성한 것이고 원본 코드를 옮긴 것이 아니다.
- 원본에서 얻은 주소·바이트 시그니처·분석 메모는 저장소와 CI 산출물에 넣지 않는다. 시그니처는 사용자의 로컬 파일로만 받는다.

## 동작

`ImportDispatcher::replace_function(runtime, 주소, 이름, 서비스)`가 함수의 첫 명령을 영구 미정의 명령(UDF)으로 바꾼다. 실행이 거기에 닿으면 디스패처가 서비스를 import처럼 호출하고 LR로 돌아간다. 호출 수는 import 집계에 `native:이름`으로 함께 나온다.

블록 캐시는 블록 첫 명령이 UDF면 범용 디코더를 거치지 않고 바로 트랩을 보고한다. 레지스터만 쓰는 함수(지금은 나눗셈 네 개)는 `replace_function_inline()`으로 레지스터 전용 함수도 같이 등록한다. 그러면 블록 실행 루프가 트랩에서 나가지 않고 그 함수를 부른 뒤 LR로 이어 간다. 거절하면(0으로 나누기) 트랩이 보고되고 서비스가 처리한다. 호출 한 번의 호스트 명령 수(callgrind, 게스트 명령 6개짜리 호출 루프 포함): 디스패처 경유 1,061 → UDF 즉시 보고 852 → 인라인 376.

서비스는 `ImportCall::decline()`으로 그 호출만 게스트 원래 코드에 넘길 수 있다(예: 0으로 나누기). 이때 원래 첫 명령을 잠시 되돌려 한 명령 실행한 뒤 다시 바꾸는데, 코드 페이지 권한이 바뀌어 블록 캐시가 비워지므로 드문 입력에만 쓴다.

`install_native_functions()`(`include/atlan/native_functions.hpp`)는 집합(`NativeSet`) 단위로 처리한다. 집합은 함께 바뀌거나 함께 남아야 하는 함수 묶음이다(같은 스트림 상태를 공유하는 zlib 호출들). 필수 멤버를 모두 찾고 검증을 통과해야 설치된다. import 서비스를 연결한 뒤, 게스트 코드를 실행하기 전에 한 번 호출한다. 결과는 로그 한 줄로 남는다: 바뀐 함수, 동작이 달라 남겨 둔 집합, 찾지 못한 집합.

## 현재 집합 (`runtime_library_sets()`)

| 집합 | 찾는 이름 | 검증 |
| --- | --- | --- |
| 정수 나눗셈 | `__aeabi_uidivmod`, `__aeabi_idivmod`, `__aeabi_uidiv`/`__udivsi3`, `__aeabi_idiv`/`__divsi3` | 경계값 조합의 몫·나머지 비교. 0으로 나누기는 게스트 코드에 넘김 |
| 체크섬 | `adler32`, `crc32` | 길이·시작값·정렬이 다른 버퍼 비교 |
| `uncompress` | `uncompress` | 동적·고정·저장 블록 스트림, 출력 부족, 잘린 입력의 반환값·길이·출력 비교 |
| inflate 스트림 | `inflateInit_`, `inflateInit2_`, `inflate`, `inflateReset`, `inflateEnd` | 입력·출력을 여러 크기로 쪼갠 세션의 반환값·최종 카운터·출력 비교 |
| PNG 행 필터 (`image_library_sets()`) | `png_read_filter_row` | 픽셀 깊이·필터 종류·행 길이 조합의 결과 행 비교. 모르는 필터 값은 게스트 코드에 넘김 |
| ETC1 디코드 (`image_library_sets()`) | `PVRTDecompressETC` | 여러 크기(블록보다 작은 밉맵 단계 포함)의 임의 블록 디코드 결과와 반환값 비교. 픽셀 바이트 순서가 다른 두 변형 중 맞는 쪽이 설치됨. 비교하지 않은 모드는 게스트 코드에 넘김 |

inflate 스트림 집합이 설치되면 디코더 내부 상태가 호스트에 있으므로 `inflateSync`·`inflateSetDictionary`·`inflateSyncPoint`가 호출될 경우 명시적으로 정지한다. 디코더(`src/inflate.cpp`)는 입력·출력을 임의 크기로 나눠 받아도 이어서 동작하며, 호스트 zlib에 의존하지 않는다.

이 집합들은 특정 앱이 아니라 툴체인과 공용 라이브러리의 표준 이름에 대한 것이라 엔진 쪽에 둔다. 앱 고유 함수를 대체하게 되면 그 집합은 어댑터가 만들어 같은 `install_native_functions()`에 넘긴다([엔진/어댑터 경계](engine-adapter.md)).

## 시그니처 파일

이미지가 이름을 export하지 않을 때만 쓴다. 한 줄에 `이름 arm|thumb HEX`이고 HEX는 두 자리씩의 바이트, 임의 바이트는 `??`, `#` 뒤는 주석이다. 고정 바이트가 8개 이상이고 첫 바이트가 고정이어야 하며, 실행 가능 영역에서 정확히 한 곳만 맞아야 채택된다. 이름은 집합 멤버 이름이다. 채택된 주소도 같은 자가 검증을 거친다.

`이름 symbol EXPORT이름` 줄은 바이트 대신 export 이름으로 찾게 한다. 앱 고유 함수의 집합은 어댑터가 `AppAdapter::native_sets()`로 내고, 멤버 이름은 일반적인 이름으로 둔다. 실제 export 이름이나 바이트는 사용자의 로컬 파일에만 있다.

- `atlan-session`: `ATLAN_NATIVE_SIGNATURES=파일`
- iOS 앱: Documents의 `native.sig`(없어도 됨)

## 진단

- `ATLAN_NO_NATIVE=1`: 전부 인터프리터로 실행. `ATLAN_NATIVE_SKIP=집합,집합`: 해당 집합만 제외.
- 대체 여부에 따라 게스트가 쓰는 명령 수가 크게 달라지므로, 프레임 수로 끊는 헤드리스 실행은 게스트의 시간 기반 대기와 어긋나 로딩 진행 정도가 달라질 수 있다. 비교는 `ATLAN_INTERACTIVE_SECONDS`로 시간을 맞춰서 한다.

## 테스트

`native-function-replacement`(`tests/native_tests.cpp`)는 합성 입력만 쓴다.

- 디코더: 세 가지 블록 형식 스트림을 여러 조각 크기로 복원, 스트림 뒤 바이트 미소비, 체크섬 불일치·잘린 입력·잘못된 헤더.
- 이미지: 테스트가 직접 건 PNG 필터를 서비스가 되돌리는지, 색을 손으로 계산한 ETC1 블록(개별·차분 모드, 뒤집힌 블록, 포화, 블록보다 작은 크기)의 디코드 결과.
- 서비스: 게스트 메모리 위의 `uncompress`·체크섬·나눗셈·스트림 인터페이스(페이지 경계, 공간 부족, 닫힌 스트림).
- 대체: 손으로 조립한 게스트 나눗셈 함수를 이름으로 찾아 검증·대체하고, 임의 입력 3,000쌍에서 인터프리터 결과와 비교(차분). 같은 이름인데 동작이 다른 코드는 대체하지 않음, 시그니처로 찾기, 모호한 시그니처 거부, decline 뒤 복귀, Thumb 함수.

실제 라이브러리에 대한 차분 검증은 로드할 때마다 자가 검증으로 수행된다.
